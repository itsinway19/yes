## Execution status

The existing shared SPA now implements both advertiser views. Only a resource projection/JSON presentation adapter was added around the existing Laravel writers. `SecurityDevicesController` keeps its internal Inertia `index` and shares the original projection with the advertiser-only `application` method. Non-JSON redirects remain; internal JSON deletion/revocation still retains its old redirect behavior. No authority classes, SQL, RLS, security timeouts, challenge verification, internal components or N1 runtime artifacts changed.

Email uses the original native PATCH method via Laravel's native form method override and current shared transport document evidence. The shared `close()` runs synchronously before native submission, clearing feature state/query memory and hiding private display. `Inertia::clearHistory()` remains required for remaining legacy documents. Native validation errors/old name/email survive the shell GET into its following JSON read; passwords are never flashed into that projection. A full login document follows successful email retirement; a lost acknowledgement stays closed and does not replay.

The installed `@simplewebauthn/browser` 13.3.0 engine is now an explicit dependency at its existing locked version, not a new authenticator/identity implementation. It performs only browser credential creation. All options/store/delete HTTP goes through the existing generated application client/transport, and the existing cross-tab ceremony guard/cancel service is reused. A confirmed cancel-during-options race was corrected at the feature boundary with an operation-scoped caller abort signal checked before browser creation. Cancellation is not presented as server-side write cancellation.

Account commands keep only pending/unknown outcome markers in identity-local memory, not a Sources command store or persisted secrets. Navigation aborts reads, converts unresolved writes to unknown, clears form secrets and warns on departure. There is no automatic write retry. Authorized rereads describe current name/session/key state without claiming the prior command was acknowledged. Password uncertainty remains unresolved until a deliberate native authentication/new-document recovery; it is not inferred from session metadata. Terminal closure clears the markers and query cache.

The two dead advertiser Profile files were deleted; the legacy Security/Devices and password component remain consumed by internal presentation. Legacy advertiser link definitions cross natively to migrated destinations; internal navigation retains its existing Inertia defaults. Actual source/runtime inventory is now **18** remaining render routes (20 before this slice), not a manually forced count; dependency ceiling is 77 files. The two journey entries record local acceptance only, not full Foundation, platform or release acceptance.
