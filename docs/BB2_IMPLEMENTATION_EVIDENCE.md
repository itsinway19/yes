## Gate 3 completion proof — 2026-10-01

Receipt generation is an acceptance/CAS counter; it is not a universal provider cursor. Progress generation is separate. COMPLETE acceptance inserts observation and required provenance first, then writes progress as the final operation in the same atomic transaction. No progress becomes visible before durable acceptance; a failure anywhere rolls back both. Partial, failed, malformed, rejected, interrupted and rolled-back runs cannot advance progress.

Current authority is checked after namespace/credential waits and before final acceptance. Command replay is idempotent but still requires current authority; competing commands use generation fencing. Reconnect invalidates progress from the prior credential epoch.
