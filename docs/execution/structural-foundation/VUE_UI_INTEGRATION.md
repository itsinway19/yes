- API الأرشفة موجود؛ سطح Business الحالي لا يعلن خيار الأرشفة المؤهل وإصداره. لا يجوز استنتاجه من صلاحية تعديل المعلومات أو نوع المستخدم. يُحسم الحد الأدنى من القراءة التشغيلية اللازمة عند المرحلة2، دون منح حق جديد.

- خيارات إنشاء النشاط لا تحمل علمcan_create؛ رابط الدخول إلى الصفحة لا يمنح الحق، وتظل أهلية العملية لدى المسار والخادم القائمين. لا يضاف محرك أهلية في Vue.
