الأقسام الرئيسية المثبتة: **الرئيسية، السوق والعملاء، العروض والخطة، الإعلانات، المبيعات والتحويل، النتائج والعائد، القرارات والتحسين**. الأقسام المساندة: **المصادر والتكاملات، النشاط والفريق والإعدادات**. تبقى الوظيفة في موضع أساسي واحد مع روابط سياقية، وليست الملاحة تسلسلًا إلزاميًا للعمل.

الموضع الأساسي لإدارة BF03 هو **النشاط والفريق والإعدادات ← البيانات والإفادات ← إفادات الاستفسارات**. البحث وروابط المبيعات والنتائج توصلك إليه. المعروض مجموعة واحدة مؤهلة التعريف في المثال: ١٠٠ تسجيل من قناة نموذج في ١–٧ أكتوبر، مع أصل الإفادة وتاريخ أولي وتصحيح توضيحي. القبول والتكلفة ومصدر الاكتساب غير معروفة؛ النموذج ليس مصدر إحالة إعلانيًا، والعدد ليس أشخاصًا فريدين أو بيعًا أو ربحًا.

BF03 الحالي حفظ/قراءة/تصحيح وتاريخ **إفادات مجمّعة خاصة بالنشاط** بحقوق مستقلة؛ لا صندوق عملاء أفراد أو CRM. أُزيلت سجلات الأفراد وإنشاؤها وتحديثها من النموذج. لم تُختلق أوامر BF03 تشغيلية أو سلطة تحليل/مشاركة/تصدير من حق القراءة. تبقى قيمة الأعداد وقنواتها وفترتها ظاهرة دون ادعاء تحقق مستقل.

الغاية اختيارية ويمكن إزالتها دون إعادة كتابة الأدلة. النتائج تستخدم لقطة تركيبية ثابتة، ولا تضرب الأعداد لتوليد فترات ٧/٩٠ يومًا أو نسب انتقال. القرارات تستخدم حالات مراجعة محلية فقط: قيد المراجعة، مكتملة محليًا، مؤجلة؛ التنفيذ والأثر غير معروفين. التبديل بين الأنشطة يحفظ السياق والمسودات والمراجعات مستقلة، والنشاط الجديد لا يرث أفرادًا أو مراجعات من غيره.

الحفظ تحت مفتاح منفصل `builderad.ux.frozen-baseline.v1`، مع تنبيه والعمل في الذاكرة عند منع التخزين. التصدير يخص عمل التصميم المحلي فقط، ويستبعد إفادات BF03؛ لا يمثل منح إذن تصدير. لا تدخل بيانات شخصية أو أسرارًا. لا OAuth أو نشر أو إجراء خارجي أو منح صلاحيات أو فوترة فعلية.

المسودات غير المرسلة للنماذج محفوظة في ذاكرة المستند بحسب النشاط والنموذج، فتعود بعد فتح نافذة أو تبديل النشاط أو الوجهة. لا تتحول إلى تصريحات محفوظة قبل الإرسال الصريح، ولا يُدّعى بقاؤها بعد إغلاق الملف. الإرسال الصريح يمسح المسودة المعنية، وإعادة الضبط تمسح المسودات كلها. أُصلح أيضًا تسليم فرضية السوق إلى المراجعة المحلية، وأصبحت الإعدادات تعرض عنوانًا رئيسيًا واحدًا.

هذا **مرجع تصميم ووثائق** يميز القائم في الكود عن التصورات الأوسع للسوق والخطط والإعلانات والمبيعات والنتائج. التنفيذ الإنتاجي يحتاج حزمة تالية مفوضة. لم يتغير Vue أو PHP أو SQL أو API أو بيانات تشغيلية.
